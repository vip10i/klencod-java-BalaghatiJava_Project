# بلاغاتي — مشروع Android أصلي بلغة Java

مشروع Android Studio بسيط لإدارة البلاغات عن المحتوى والحسابات على TikTok وInstagram وFacebook.

## فتح المشروع
1. فك ضغط ملف المشروع.
2. افتح Android Studio أو IDE يدعم مشاريع Android Gradle.
3. اختر **Open** وحدد مجلد `BalaghatiJava` (المجلد الذي يحتوي على `settings.gradle`).
4. انتظر مزامنة Gradle ثم شغّل التطبيق على جهاز افتراضي أو هاتف متصل.

## بناء APK
في Android Studio: **Build > Build APK(s)**. بعد انتهاء البناء سيظهر مسار ملف APK في إشعار البناء.

## المميزات
- واجهة عربية RTL.
- اختيار المنصة ونوع المشكلة.
- إدخال رابط الحساب/المحتوى ووصف الواقعة.
- حفظ البلاغات محليًا باستخدام SharedPreferences.
- فتح صفحات المساعدة الرسمية للمنصات.
- حذف السجل المحلي.

## ملاحظات
- هذا مصدر مشروع Android Java، وليس ملف APK مبنيًا وجاهزًا.
- يحتاج Android Studio/Gradle وAndroid SDK لبناء APK.
- لا يرسل بلاغات تلقائية ولا يضمن إغلاق أي حساب. استخدم القنوات الرسمية للبلاغات الصحيحة فقط.
- البيانات محلية على الجهاز؛ لا تدخل كلمات مرور أو رموز تحقق أو معلومات حساسة.
